# Book Management App

A simple client-side application for managing a personal book library.

## Features

- Add books with a title and author.
- Store optional information such as publication year, genre, and description.
- Select a reading status: To Read, Reading, or Read.
- Search books by title or author.
- Save books in the browser using Local Storage.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- JavaScript modules
- Browser Local Storage

## Project Structure

- `index.html` — application structure.
- `style.css` — styling and responsive layout.
- `app.js` — application setup and event handling.
- `state.js` — book data and Local Storage.
- `ui.js` — displaying books in the interface.
- `utils.js` — validation helper functions.

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.

## Data Storage

Books are stored in the browser's Local Storage. Data is saved locally in the browser and is not automatically shared between different browsers or devices.
